# TCOOL 小一至小四數學段考題庫

來源：<https://www.tcool.cc/>

篩選條件：小一至小四、數學、康軒／翰林、不限學期與段考、具題目卷與答案卷。

每個年級／出版社資料夾包含：

- `manifest.json`：來源列、題目卷／答案卷 URL、頁碼、學校、學期與本機檔名。
- `manifest.csv`：方便用試算表盤點。
- `download_summary.json`：下載數量與 PDF 檔頭驗證結果。
- `questions/`、`answers/`：原始 PDF 僅保留在本機，不納入 Git 版本控制。

TCOOL 分頁可能重複列出邊界資料；清單以題目卷檔名去重，保留第一次出現的來源列。
