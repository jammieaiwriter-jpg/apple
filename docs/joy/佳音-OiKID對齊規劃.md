# 佳音與 OiKID 對齊規劃

建立日期：2026-06-22

## 結論

可以對齊。佳音適合當「主課程」，OiKID 適合當「輔助口說、聽力、情境反覆練習」。目前資料夾裡的佳音掃描內容約涵蓋 Unit 1-20；OiKID 現有 LV1-19 到 LV1-68 中，有幾個單元能直接補強佳音的問候、顏色、教室文具、水果食物、動作指令與物品描述。

規劃原則：

1. 佳音上課前：用 OiKID 做 8-12 分鐘預習，重點是聽音、跟讀、熟悉情境，不要求拼字完全記住。
2. 佳音上課後：用 OiKID review 或自製練習做 10-15 分鐘複習，重點是單字回想、句型替換、口說穩定。
3. OiKID 不硬塞每一課。只挑主題、單字或句型真的接近的單元。

## 建議學習節奏

### 課前預習

每次佳音上課前 1 天或當天：

1. 聽 OiKID 對齊單元的 chant / dialogue 1 次。
2. 跟讀 4-6 個關鍵字。
3. 跟讀 2-3 句核心句型。
4. 做 1 個簡單口說任務，例如：
   - My name is Bobo.
   - I am good.
   - The apple is red.
   - This is my book.

### 課後練習

佳音下課當天或隔天：

1. 先複習佳音本課單字 5-8 個。
2. 做 OiKID review 或自製拼字格，特別補容易忘的字。
3. 做句型替換，讓孩子把佳音單字放進 OiKID 句型：
   - This is my book / bag / marker.
   - It is red / blue / yellow.
   - I can sing / dance / run.
4. 最後錄音或口說 2 次成功才算完成。

## 後續可做的成品

1. 建立「佳音 Unit 1-20 對齊表」：每課列出佳音單字、句型、可搭 OiKID、課前任務、課後任務。
2. 產生 Bobo 專用 HTML：每個佳音單元做一頁課前預習和一頁課後練習。
3. 建立錯字/弱點追蹤：把 Bobo 常錯的拼字和口說項目記錄下來，下次自動加強。

## 注意事項

- 佳音掃描 PDF 是圖片型，OCR 對密集表格不穩，這份規劃以人工讀圖校正為主。
- OiKID LV1 內容比佳音有些地方更生活化，建議只取對齊段落，不需要整份完整做完。
- 如果要做成 HTML，課前頁應偏「聽、跟讀、看圖說」，課後頁才加入拼字格與較嚴格的口說通關。
