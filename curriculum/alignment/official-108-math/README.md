# 108 數學領綱官方基準（G1-G4）

這個目錄是考卷與現有 SkillID 對齊的上位基準，不是練習題庫，也不直接決定出版社章節或段考範圍。

權威順序如下：

1. `sources/108-math-curriculum-moe-20180726.pdf`：教育部 107 年 7 月 26 日發布的數學領綱，是學習內容代碼、年級安排、條目、說明與備註的唯一規範來源。
2. `sources/108-math-course-manual-naer-202501.pdf`：國家教育研究院 114 年 1 月更新的數學領域課程手冊，只用來解釋與落實條文，不得推翻第一項。
3. 康軒、翰林的版本目錄、段考卷面與答案卷，僅能用來建立教材與題目證據。

`official-codes-g1-g4.json` 逐筆保存 G1-G4 的官方學習內容代碼。逐題對齊時，先選擇 `code`，再以 `description`、`notes` 和 `learning_performance_codes` 確認年級邊界；不要只看章節名稱或題目關鍵字。

對齊鏈為：

`官方學習內容代碼 → 出版社章節／小節 → 現有 SkillID → 段考範圍 → 考卷逐題證據`

一個官方代碼可對應多個 SkillID，一個 SkillID 也可能橫跨多個官方代碼。現有 SkillID 是執行層穩定識別碼，第一輪不得更名、刪除或以出版社版本取代。

官方 ODT 的下載連結記錄在 `source-manifest.json`。其伺服器在封存時連線逾時；ODT 與教育部發布 PDF 為同一領綱的不同檔案格式，因此不影響此基準的權威性或可追溯性。
