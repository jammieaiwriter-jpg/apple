# Piano samples

These MP3 files are selected notes from **Salamander Grand Piano V3**, recorded by Alexander Holm and distributed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).

- Source library: https://archive.org/details/SalamanderGrandPianoV3
- MP3 distribution: `@audio-samples/piano-mp3-velocity2` via unpkg
- Files used: `C2v2.mp3`, `C3v2.mp3`, `C4v2.mp3`, `C5v2.mp3`
- Local names: `C2.mp3`, `C3.mp3`, `C4.mp3`, `C5.mp3`

The files are used with pitch shifting to cover the app's C2–B5 teaching range. No endorsement by the original author is implied.
